## Discipline (MRVN-09, identical to MRVN-08)

* Every candidate must use `LAWS.bend` whose sha256 equals
  `canonical_laws_sha256`.  Drift → `DIFFERENT_SPECIFICATION`.
* Every candidate's intent comparison must use `oracle.json` whose
  sha256 equals `INTENT_ORACLE_SHA256`.  Drift →
  `BEHAVIOR_EVIDENCE_MISMATCH`.
* Every candidate's behavior is generated by executing Bend, not by
  hand-written mirror code.  Drift → `BEHAVIOR_EVIDENCE_MISMATCH`.
* Canonical `PROOF.bend` (sha256 = `canonical_proof_sha256`) is run
  byte-identical.  If it fails, REPROOF.bend may be authored (up to
  `MAX_REPROOF_ATTEMPTS = 3`).
* Toolchain closure is byte-for-byte bound; drift → `TOOLCHAIN_MISMATCH`.
* **Independence:** the agent that generates MRVN-09 candidates MUST
  NOT have received MRVN-08 candidate implementations, descriptors,
  transformation recipes, or commentary.  Exposure →
  `INDEPENDENCE_AUTHORITY_FAILURE`.

## Verdict policy

* If at least 12 valid independent candidates are produced and all
  preserve canonical proof (and no EXTENSIONAL_PROOF_BREAK), the
  verdict is `FULL_QUALIFICATION_NO_PROOF_BREAK_FOUND_WITHIN_SEARCH_BOUND`.
* If an EXTENSIONAL_PROOF_BREAK is found, the verdict is
  `FULL_QUALIFICATION_WITH_EXTENSIONAL_PROOF_BREAK_FOUND`.
* If independent replication cannot be completed, the verdict is
  `PARTIAL_QUALIFICATION_INDEPENDENT_REPLICATION_INCOMPLETE`.
* If independence cannot be established, the verdict is
  `HALT_INDEPENDENT_AGENT_UNAVAILABLE` or
  `INDEPENDENCE_AUTHORITY_FAILURE`.
